# start.gg Deluxe

**start.gg Deluxe** est un tableau de bord pensé pour **gérer le tournoi sur place** : un **plan de la salle** avec tes setups, le **bracket** du tournoi start.gg, et de quoi suivre les matchs. Il s'organise en **fenêtres flottantes** (façon bureau Windows) que tu peux déplacer, redimensionner et réduire.

## Se connecter à un tournoi

En haut, colle l'**URL ou le slug** d'un tournoi start.gg et clique sur **🔗 Charger** (ou **↻ Rafraîchir** pour recharger les matchs). Le bracket et les matchs se remplissent.

## 🗺️ Fenêtre Plan

Le plan représente ta **salle** et tes **setups**.

* **Deux modes**, via le bouton flottant ✏️ :
  * **Mode Tournoi** — pour suivre le déroulé (par défaut).
  * **Mode Édition** — pour modifier le plan.
* **En mode Édition :**
  * Choisis un type d'élément dans la liste puis **+ Ajouter** (setups, murs, portes…).
  * **Glisse** pour déplacer, **double-clic** pour renommer, **✕** pour supprimer.
  * Le **panneau de propriétés** (au clic sur un élément) permet de régler finement : label, **X / Y / largeur / hauteur**, couleur, **rotation 90°**, type de porte (simple/double), sens d'ouverture.
  * **↺ Plan par défaut** restaure le plan d'origine (⚠️ perd tes modifications).
* **Zoom** en bas à droite (+ / − / 100%).

## 🏆 Fenêtre Bracket

Affiche le **bracket** du tournoi chargé, avec ses différentes phases (chips) et un zoom dédié. Tant qu'aucun tournoi n'est chargé, elle invite à en charger un.

## Organiser ses fenêtres

Chaque fenêtre a une **barre de titre** (glisse pour déplacer), un bouton **réduire −**, et une **poignée** en bas pour redimensionner. Tu composes ton espace de travail selon tes besoins du moment.

{% hint style="info" %}
Le plan que tu construis est enregistré dans ton navigateur : tu le retrouves à la prochaine ouverture. Pense à le sauvegarder sur le bot (via la Configuration) si tu veux le retrouver sur un autre PC.
{% endhint %}
