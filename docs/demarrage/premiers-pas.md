# Premiers pas

## Ouvrir l'application

Projet Rêverie est un site web — aucune installation nécessaire.

👉 Va sur **[kiokouwhite.github.io/projet-reverie](https://kiokouwhite.github.io/projet-reverie/)**

Pour un accès rapide, ajoute la page à tes favoris ou épingle l'onglet.

{% hint style="info" %}
L'app fonctionne sur tous les navigateurs modernes (Chrome, Firefox, Edge, Opera GX…). Certaines animations 3D (comme le cube des Horaires) dépendent de l'accélération matérielle du navigateur ; l'app bascule automatiquement sur une version simplifiée si besoin.
{% endhint %}

## L'écran d'accueil

Au chargement, tu arrives sur la **grille des outils**. Chaque tuile ouvre un outil :

* 🏆 TOP8 Generator
* 📢 Annonce Discord
* 🗓️ Horaires
* 🎮 Tournoi start.gg
* ✨ start.gg Deluxe
* ⚙️ Configuration

Clique sur une tuile pour entrer dans l'outil. Le logo « Projet Rêverie » en haut te ramène à l'accueil à tout moment.

## Où sont stockées mes données ?

Tout ce que tu saisis (clé API, réglages du bot, modèles de cartes, préférences) est enregistré **dans ton navigateur**, sur ton ordinateur. Concrètement :

* ✅ Tes données **survivent** quand tu fermes l'onglet ou éteins le PC.
* ⚠️ Elles sont **liées à ce navigateur, sur cet ordinateur**. Sur un autre PC ou après avoir vidé le cache, il faut reconfigurer.
* 🔒 La **clé API start.gg** ne quitte jamais ton navigateur.

### Sauvegarde et restauration

L'app peut sauvegarder tes modèles, presets et préférences **sur le bot** (routes de backup), pour les retrouver sur un autre appareil. Ça se pilote depuis l'onglet **⚙️ Configuration**. La clé API, elle, n'est **jamais** sauvegardée en ligne (par sécurité).

## Astuce : recharger après une mise à jour

L'app est mise à jour régulièrement. Si un changement n'apparaît pas, force le rechargement :

* **Chrome / Edge / Firefox :** `Ctrl + F5`
* **Opera GX :** `Ctrl + F5` (ou `F12` → clic droit sur ↻ → « Vider le cache et actualiser »)

Laisse passer ~1 minute après une mise à jour : GitHub Pages met parfois un court instant à propager la nouvelle version.
